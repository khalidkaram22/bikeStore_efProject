# 🚲 BikeStore EF Core Queries

A simple C# Console Application built with **Entity Framework Core** using the **Database First** approach to practice LINQ queries on the BikeStore sample database.

---

## 1. 📌 Project Overview

This project demonstrates how to use **Entity Framework Core** and **LINQ** to retrieve and analyze data from the BikeStore database.

The database was scaffolded using the **Database First** approach and all queries were implemented using LINQ.

## ✅ Implemented Queries

- Retrieve all categories
- Retrieve the first product
- Retrieve a product by ID
- Retrieve products by model year
- Retrieve a customer by ID
- Retrieve product names with their corresponding brand names
- Count products in each category
- Calculate the total list price of products for each category
- Calculate the average list price of all products
- Retrieve completed orders

## 🚀 Getting Started

### 1. Clone the repository

```bash
ghttps://github.com/khalidkaram22/bikeStore_EF_core.git
```

### 2. Open the solution

Open the project using **Visual Studio 2022**.

### 3. Restore NuGet packages

Restore the required NuGet packages if needed.

### 4. Configure the connection string

Update the SQL Server connection string to match your local SQL Server instance.

### 5. Run the project

Start the console application and choose a query from the menu.
